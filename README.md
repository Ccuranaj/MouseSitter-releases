# MouseSitter

A small app that shows on your **mouse cursor** what your AI coding agents are doing: Claude Code, Codex, Cursor, Gemini CLI, Aider, or anything that can run a command. A badge appears when an agent finishes or needs you, and a shortcut jumps you straight back to it.

This repository holds the downloads. Get the newest version from **[Releases](https://github.com/Ccuranaj/MouseSitter-releases/releases)**.

| | Download | Then |
|---|---|---|
| **Windows** 10 or 11 | `MouseSitter.exe` from the newest `v…` release | Run it; it installs itself for your account, no admin rights needed |
| **macOS** 13 or newer | `MouseSitter-mac-v….zip` from the newest `mac-v…` release | Unzip, drag MouseSitter to Applications and open it |

Both apps check here for updates once a day and offer to install them in one click, keeping your settings, rules, stats and agent hooks.

MouseSitter was called **AgentMouse** up to Windows 1.4.1 and Mac 1.0.2. Those versions can't update themselves to MouseSitter: download it once, and it takes over your settings, stats and agent hooks from AgentMouse, then removes the old app.
